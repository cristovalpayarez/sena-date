# SENA-DATE-CRISOVALPAYAREZGALVAN
una utilidad para manejar fechas en formato timestamp y log time

## Install

```bash
npm install sena-date-cristovalpayarezgalvan

```
## Uso

```js

const { getTimeStamp, getLongTime } = require('sena-date-cristovalpayarezgavan')

getTimeStamp();
getLongTime(es-'ES');
```
